Chained Laspeyres · Paasche · Fisher indexes

Price (p)=close, quantity (q)=volume. Links chained from first date = 100. Compute in DuckDB-Wasm runs the same SQL as run_fisher_duckdb.py in-browser; Chart.js renders Laspeyres / Paasche / Fisher / nominal paths. Nominal √(Fisher_P × Fisher_Q) tracks the geometric value index; Fisher_P × Fisher_Q matches the nominal value ratio path.

Identity: (1 + π)·(1 + g) = (1 + n) on Fisher links, where π = price inflation (Fisher_P link − 1), g = real/quantity growth (Fisher_Q link − 1), n = nominal value growth (Fisher_P×Fisher_Q link − 1). Default reference = first date of the series (or 1y lookback when longer).
